## Featured work

### [EduSync](https://github.com/Triplejw/EduSync) - Edge AI Learning Management System

A mobile-first LMS that runs AI inference locally, giving educators and learners a privacy-first alternative to cloud-dependent tools.

- Generates summaries, flashcards, and quizzes from study material with a 4-bit quantized Llama 3 model.
- Uses FIR filtering, zero-crossing rate analysis, and FFT-based features to model scroll engagement.
- Adds vision-based attention estimation with MediaPipe Face Mesh and head-pose analysis.
- Built with React Native, FastAPI, SQLite, EasyOCR, OpenCV, and MediaPipe.

**IEEE publication:** [*EduSync: DSP-Based Engagement Modeling and Vision Analytics in an Edge-Deployed LMS*](https://doi.org/10.1109/AIMLA67915.2026.11522309), presented at IEEE AIMLA 2026.
